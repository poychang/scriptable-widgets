# Scriptable Widgets

這個專案用來收集我撰寫與整理的 [Scriptable](https://scriptable.app/) 腳本，主要以 iPhone、iPad 上的 Scriptable 小工具與自動化用途為主。

## 關於 Scriptable

[Scriptable](https://scriptable.app/) 是一款使用 JavaScript 建立小工具與自動化腳本的 App。透過它可以存取裝置資訊、行事曆、提醒事項、檔案、網路服務等功能，並將資料呈現在主畫面小工具中。

## 使用方式

1. 在裝置上安裝 [Scriptable](https://apps.apple.com/tw/app/scriptable/id1405459188)。
2. 開啟本專案中想使用的 `.js` 腳本。
3. 將腳本內容複製到 Scriptable，或依照個別腳本的說明設定必要參數。
4. 儲存後直接執行，或將腳本加入主畫面小工具與自動化流程。

部分腳本可能需要自行設定 API Token、網址、位置或其他個人化資訊；使用前請先閱讀腳本內的註解與說明。
